# Saint-Victor · Paintball

Paintball dans le domaine du Château Saint-Victor (Marseille), jouable dans le navigateur.

Le jeu est désormais servi sur https://paintball-saint-victor.marseille-tech.workers.dev , réservé aux comptes Google autorisés.
Cette page GitHub Pages ne fait que rediriger vers cette adresse.
